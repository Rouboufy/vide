# VIDE bug-report gateway

This Cloudflare Worker receives the in-app report and creates an issue through
a GitHub App. GitHub credentials remain in encrypted Worker secrets; VIDE and
its users never receive or handle them.

## One-time GitHub setup

1. Create a GitHub App owned by the repository owner.
2. Give it **Issues: Read and write** and **Metadata: Read-only** repository
   permissions. It needs no user permissions or webhook.
3. Install it only on `Rouboufy/vide` and record the App and installation IDs.
4. Generate and download a private key. Keep it outside this repository.

GitHub installation tokens are short-lived and are generated by the Worker for
the single configured repository.

## Deploy

```sh
cd reporting
npm install
npx wrangler login
npx wrangler kv namespace create REPORT_LIMITS
```

Put the returned namespace ID in `wrangler.toml`, then configure secrets. Run
these commands yourself; do not paste their values into source files or chat:

```sh
npx wrangler secret put GH_APP_ID
npx wrangler secret put GH_INSTALLATION_ID
npx wrangler secret put GH_PRIVATE_KEY
npm run deploy
```

Build VIDE with the resulting HTTPS Worker URL:

```sh
zig build -Dbug-report-endpoint=https://vide-bug-report.YOUR_SUBDOMAIN.workers.dev
```

For tagged GitHub releases, save the same URL as the repository Actions
variable `VIDE_BUG_REPORT_ENDPOINT`. The release workflow embeds it in every
native binary and the AppImage without treating the public endpoint as a
credential.

For a local build, `VIDE_BUG_REPORT_ENDPOINT` overrides the compiled URL. This
is an endpoint URL, not a credential.

## Abuse and privacy controls

- Reports are limited to five per source IP per hour using Workers KV.
- Input fields and request size are strictly bounded.
- The client reads logs only after explicit consent, limits them to 32 KiB,
  and redacts common credential formats and the user's home path.
- Basic diagnostics include OS/version, kernel, architecture, display server,
  desktop session, terminal, `TERM`, shell, and VIDE version. They exclude the
  username, hostname, and arbitrary environment variables.
- The gateway does not log report bodies or source IPs.
